# Demo and recording checklist

## Before a take

- [ ] Independent API environments installed; runner completes its actual assertions.
- [ ] Fresh temporary fixture scenario; no real data or cloud mode.
- [ ] Calculator reachable; correct `/console` origins from the runner.
- [ ] Session keys loaded off-record; no tokens in URL, recording, clipboard overlay or terminal capture.
- [ ] Additional invoice source is synthetic; previous take has not created the same invoice number in this session.
- [ ] Operator/reviewer/exporter roles and workflow reviewer are distinguishable.
- [ ] Notifications and unrelated tabs hidden; source fields readable.

## During the demonstration

- [ ] Say “JSON fields,” not “OCR,” for the deterministic import.
- [ ] Show denied operator approval, independent decision and audit state.
- [ ] Label fixture planning, lexical retrieval and local mock effects.
- [ ] Show invoice/policy receipts without implying the model owns authorization.
- [ ] Explain unsafe evaluation as a deliberate negative control.
- [ ] Show hypothetical assumptions; never narrate a capacity estimate as client savings.
- [ ] State Azure and full Microsoft runtime limits; do not fabricate a conversation.

## Release the video only after personal review

- [ ] Actual exported file exists, plays from start to finish, and duration is recorded.
- [ ] No secrets, personal windows or real customer data appear.
- [ ] Captions/transcript and synthetic-data labels are readable.
- [ ] Every asserted action was performed or clearly labelled as screenshot/B-roll.
- [ ] Publication destination/link works; website/LinkedIn copy points to an actual video.
- [ ] Runner and calculator stopped normally; session file removed.
